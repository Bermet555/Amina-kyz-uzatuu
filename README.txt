АМИНАНЫН КЫЗ УЗАТУУСУ — ЭЛЕКТРОНДУК ЧАКЫРУУ

КАНТИП АЧУУ:
1. ZIP архивди толугу менен чыгарыңыз (Extract All).
2. index.html файлын Chrome же башка браузер менен ачыңыз.
3. Интернет күйүп турса, шрифттер жана оригинал чакыруудагы сүрөттөр жүктөлөт.

ТЕКСТТЕРДИ ӨЗГӨРТҮҮ:
- data.js файлын Блокнот менен ачыңыз.
- brideName, invitationText, dateISO, dateLong, time, venueName, venueAddress жана hosts маанилерин өзгөртүңүз.
- dateISO форматы: YYYY-MM-DDTHH:MM (мисалы: 2026-12-18T16:00:00).
- Сактап, браузердеги баракты жаңыртыңыз (Ctrl+R).

ЭСКЕРТҮҮ:
Бул чакыруу референстеги жалпы композицияга ылайыкташтырылган өз алдынча веб-баракча. RSVP формасы жоопту WhatsApp аркылуу жөнөтүүгө даярдайт. Карта шилтемеси Google Maps издөөсүн ачат.
